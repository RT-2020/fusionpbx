## 🔧 使用方法

### 快速开始

1. 访问操作面板页面
2. 点击顶部"注册"按钮
3. 填写 SIP 配置信息
4. 注册成功后即可使用所有调度功能

### 组呼操作

1. 点击 ⚙️ 创建呼叫分组
2. 点击 👥 选择分组发起组呼
3. 查看顶部状态栏了解呼叫状态

### 会议操作

1. 点击 🎥 会议按钮
2. 勾选参与分机
3. 发起会议
4. 使用管理按钮控制会议

## ⚠️ 注意事项

1. **HTTPS 环境**：使用 HTTPS 访问时必须配置 WSS（端口 7443）
2. **证书信任**：自签名证书需在浏览器中信任
3. **FreeSWITCH 配置**：确保启用了 wss-binding
4. **浏览器支持**：需要支持 WebRTC 的现代浏览器
