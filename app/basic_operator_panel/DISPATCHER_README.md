# 调度终端功能使用说明

## 概述

本调度终端系统为 FusionPBX 操作面板增加了以下功能：
1. **中继汇接**：支持人工中继和自动中继
2. **组呼全呼**：支持组呼和全呼功能，带发言权控制
3. **多方会议**：支持多方会议，可动态添加/移除参与者

## 功能特性

### 1. 中继汇接功能

#### 人工中继模式
- 调度员接听中继来电
- 支持保留功能（暂时保持中继通话，与其他用户通话）
- 支持人工桥接（将中继呼叫转接到目标用户后退出）

#### 自动中继模式
- 自动接听中继来电
- 自动提示输入目标号码
- 自动转接到目标用户

**使用方法：**
1. 点击"人工中继"按钮启用人工模式
2. 点击"自动中继"按钮切换自动模式
3. 收到中继来电时：
   - 人工模式：点击"应答"接听，然后输入目标号码进行桥接
   - 自动模式：直接输入目标号码自动转接

### 2. 组呼全呼功能

#### 组呼
- 预先配置呼叫分组
- 一键呼叫组内所有成员
- 支持调度员单向讲话（禁止成员发言）
- 支持授权特定成员发言

#### 全呼
- 一键呼叫所有在线用户
- 功能同组呼

**使用方法：**
1. 点击"分组管理"配置呼叫组
2. 添加分组并添加成员分机号
3. 点击"组呼"选择要呼叫的组
4. 点击"全呼"呼叫所有用户
5. 在组呼面板中：
   - "静音调度员"：切换调度员单向讲话模式
   - "禁言"/"发言"：控制单个成员的发言权
   - "结束组呼"：结束所有呼叫

### 3. 多方会议功能

- 同时呼叫多个用户（2个以上）
- 支持添加新参与者
- 支持移除参与者
- 支持控制参与者发言权

**使用方法：**
1. 点击"多方会议"按钮
2. 输入参与会议的分机号（用逗号分隔），例如：`1001,1002,1003`
3. 系统自动呼叫所有参与者
4. 在会议面板中：
   - "添加参与者"：呼叫新成员加入会议
   - "禁止发言"/"允许发言"：控制成员发言权
   - "移除"：将成员踢出会议
   - "结束会议"：结束整个会议

## 配置说明

### SIP 配置

首次使用需要配置 SIP 连接信息：

```
SIP URI: sip:调度员分机号@服务器地址
例如: sip:1000@192.168.1.100

WebSocket 服务器: ws://服务器地址:端口
例如: ws://192.168.1.100:5066

用户名: 调度员分机号
例如: 1000

密码: SIP 密码
例如: 1234

显示名称: 调度员
```

配置会自动保存在浏览器本地存储中。

### 中继号码识别

系统通过以下规则识别中继号码：
- 以 0 开头的号码
- 号码长度超过 6 位

可在 `dispatcher-control.js` 的 `isTrunkNumber` 函数中自定义规则。

### 呼叫分组配置

1. 点击"分组管理"按钮
2. 点击"新建分组"
3. 输入组 ID 和组名称
4. 点击"添加成员"输入分机号
5. 配置自动保存在浏览器本地存储中

## 技术架构

### 前端技术栈
- **JsSIP v3.10.1**: WebRTC SIP 协议栈
- **jQuery**: DOM 操作和 AJAX
- **原生 JavaScript**: 调度控制逻辑

### 核心模块

#### jssip-client.js
JsSIP 客户端封装，提供：
- SIP 注册/注销
- 呼叫发起/接听/挂断
- 通话控制（保持、静音、转接）
- 批量呼叫支持
- 会话管理

#### dispatcher-control.js
调度控制逻辑，实现：
- 中继汇接（人工/自动）
- 组呼全呼
- 多方会议
- 分组管理
- UI 更新

#### dispatcher.css
调度界面样式

## 浏览器要求

- Chrome 60+ / Firefox 60+ / Edge 79+
- 支持 WebRTC
- 需要允许麦克风权限

## 使用流程

### 初次使用

1. 打开操作面板页面
2. 点击右侧的"调度控制台"中的"注册"按钮
3. 填写 SIP 配置信息
4. 点击"确认注册"
5. 等待注册成功（状态变为"已注册"）
6. 所有调度功能按钮将被启用

### 日常使用

**人工中继场景：**
1. 确保"人工中继"模式已激活
2. 收到中继来电时，调度员看到来电提示
3. 点击"应答"接听
4. 在桥接面板输入目标号码
5. 点击"桥接"完成转接
6. 调度员自动退出，双方继续通话

**组呼场景：**
1. 提前配置呼叫分组
2. 点击"组呼"选择目标组
3. 系统自动呼叫组内所有成员
4. 调度员可以讲话，所有成员都能听到
5. 点击"禁言"阻止某成员发言
6. 点击"结束组呼"结束

**多方会议场景：**
1. 点击"多方会议"
2. 输入参与者分机号（逗号分隔）
3. 系统自动呼叫所有参与者
4. 任意参与者都可发言
5. 调度员可控制发言权
6. 点击"结束会议"结束

## 注意事项

1. **麦克风权限**：首次使用时浏览器会请求麦克风权限，必须允许
2. **网络要求**：需要稳定的网络连接，建议使用有线网络
3. **并发限制**：浏览器可能限制同时进行的 WebRTC 会话数量（通常 10-20 个）
4. **音频质量**：大量并发会话可能影响音频质量
5. **保持活跃**：长时间未操作可能导致 SIP 注册过期，需重新注册

## 故障排除

### 无法注册
- 检查 WebSocket 服务器地址是否正确
- 检查网络连接
- 检查防火墙设置
- 检查用户名密码是否正确

### 无法呼叫
- 确认已成功注册
- 检查目标号码格式
- 检查麦克风权限

### 音频问题
- 检查浏览器麦克风权限
- 检查系统音量设置
- 尝试重新注册

### 批量呼叫失败
- 检查目标分机是否在线
- 减少并发呼叫数量
- 检查网络带宽

## 开发与扩展

### 自定义中继识别规则

编辑 `dispatcher-control.js`：

```javascript
DispatcherControl.prototype.isTrunkNumber = function(uri) {
    var number = uri.match(/sip:(\d+)@/);
    if (number && number[1]) {
        // 自定义规则
        return number[1].startsWith('9'); // 例如：9开头视为中继
    }
    return false;
};
```

### 添加新的呼叫组

通过界面操作或直接修改 localStorage：

```javascript
localStorage.setItem('dispatcher_call_groups', JSON.stringify({
    'group1': {
        name: '部门1',
        extensions: ['1001', '1002', '1003']
    },
    'group2': {
        name: '部门2',
        extensions: ['2001', '2002', '2003']
    }
}));
```
