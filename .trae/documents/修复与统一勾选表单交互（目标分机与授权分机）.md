# 目标
- 修复“目标分机”勾选表单可交互、可保存与正确回显。
- 为“授权分机（可拨入）”新增可输入框，与勾选双向同步；修复保存与回显逻辑。
- 统一两处的前端与后端数据处理方式，保证交互一致、提交与解析一致。

## 页面与前端交互（conference_edit.php）
### 1. 目标分机（组呼）
- 保留现有复选框列表与文本输入框 `call_mode_targets_input`。
- 新增双向同步事件：
  1) 勾选复选框 → 自动更新 `call_mode_targets_input`（英文逗号分隔）。
  2) 修改 `call_mode_targets_input` → 自动勾选对应复选框（无效分机忽略）。
- 事件绑定：`change`（checkbox）、`input`/`blur`（文本框）；初始化时执行一次同步。

### 2. 授权分机（可拨入）
- 新增文本输入框 `authorized_extensions_input`（用于输入分机号，英文逗号分隔；中文分隔符/空格统一转换）。
- 双向同步事件：
  1) 勾选复选框（值为 `extension_uuid`）→ 根据映射表（`extension_uuid` ↔ `extension/number_alias`）自动更新 `authorized_extensions_input` 的分机号列表。
  2) 修改 `authorized_extensions_input` → 将输入的分机号映射为 `extension_uuid`，勾选对应复选框；未匹配分机忽略。
- 初始化：根据已加载的白名单 `authorized_extension_uuids`，生成 `authorized_extensions_input` 的初始分机号串。

### 3. JS 辅助数据与方法
- 在页面渲染时构造 `extensionsMap`：`{ extension: extension_uuid, number_alias: extension_uuid }` 与反向 `uuidToNumber`：`{ extension_uuid: extension || number_alias }`；用于映射。
- 公共工具：标准化分隔符（中文逗号/分号/顿号/空格→英文逗号）、去重、过滤空。
- 现有联动方法保留：`toggle_target_group()`、`toggle_authorized_extensions()`。

## 后端解析与保存（conference_edit.php）
### 4. 目标分机（组呼）
- 现有合并逻辑保留：`call_mode_targets_select[]` 与 `call_mode_targets_input` 合并 → `targets_list`；并在 `group_call` 校验分机存在（已实现）。

### 5. 授权分机（可拨入）
- 新增对 `authorized_extensions_input` 的解析：
  - 读取并规范化分机号列表 → 查询 `v_extensions` 获取对应 `extension_uuid` 集合。
  - 与勾选的 `authorized_extensions_select[]`（`extension_uuid`）合并去重 → `authorized_extension_uuids_final`。
- 保存：
  - 当启用拨入授权时，先删除旧白名单，再批量写入 `v_conference_authorized_extensions`（以 `extension_uuid` 保存）。
- 回显：
  - 预加载白名单 `authorized_extension_uuids` 后，渲染复选框勾选状态，并以映射表生成 `authorized_extensions_input` 初始值（分机号串）。

## 权限与升级
### 6. 升级与表存在性
- 确认 `v_conference_authorized_extensions` 与 `v_conference_authorization_logs` 已在 `app_config.php` 正确注册；GUI 执行“高级→升级→Schema、App Defaults”。
- 若升级前报错（此前 `$y++` 索引问题已修复），再次执行升级；否则保存与回显查询会为空。

### 7. 权限策略
- 白名单保存：沿用当前临时权限 + `database->save` 批量写入；不新增额外权限项，避免权限破坏。

## 交互一致性与错误处理
- 分隔符标准化：中文逗号/分号/顿号/空格统一为英文逗号，前后端一致。
- 目标分机与授权分机均采用“分机号输入 + 勾选复选框”的统一交互；授权保存层面转换为 `extension_uuid`。
- 无效输入分机号忽略，不报错；可选在提交时提示“包含不存在分机号”，与组呼现有提示一致。

## 测试用例
1) 组呼：仅勾选复选框保存；仅输入文本保存；同时勾选与输入并去重保存；保存后回显正确。
2) 授权：仅勾选保存（白名单可拨入）；仅输入文本保存（白名单可拨入）；同时勾选与输入保存；保存后复选框与输入框回显一致。
3) 关闭拨入授权：隐藏授权分机区；保存后任意分机可拨入；再次开启授权后白名单仍回显。
4) 无效分机输入：文本包含不存在分机；组呼提示并阻止保存（维持现有行为）；授权忽略无效项并仅保存有效项。
5) 兼容性：页面其它字段保存与回显不受影响；组/全呼运行期逻辑正常。
